process learnings, and the open edges.**

## 1. The meta-lesson: gates work — in both directions

The single most valuable engineering decision of the window was insisting
that **no analysis stage writes to the library without a measured agreement
number**. The number decides, not the vibes.

| Stage                          | Gate result                                                                             | Consequence                                                                                |
| ------------------------------ | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| Key (OpenKeyScan)              | **80.7% exact** vs rekordbox on all 88 (71 exact + 8 near + 9 mismatch) vs the ≥80% bar | Passed → TKEY + TXXX:CAMELOT batch-written into every file                                 |
| BPM (beat_this)                | **12/24 then 16/24** within 2% on the 24-track sample                                   | Failed twice → TBPM writes blocked; value shipped as the DB beats ledger instead           |
| Electronic genre (effnet head) | **Saturated 0.87–1.0 on every genre including Ambient**                                 | Zero discrimination → writes blocked, deferred indefinitely (no ONNX export exists anyway) |
| Mood/dance/VA                  | Differentiation confirmed (happy 0.04–0.99, aggressive 0.01–0.98)                       | Shipped → 88/88 stamped                                                                    |

Why this matters more than it looks:

- The BPM failure is the interesting one. beat_this is ISMIR-2024 SOTA, and
  its output is _consistently, plausibly wrong_ — a locked ~2.2–2.6%
  beat-period offset vs rekordbox (130.43 vs 127.66-class pairs) on half
  the sample. No listener would notice one track drifting 2%; every
  sync/beatjump would. **A model can be wrong in a way that is invisible
  per-sample and systemic in aggregate.** Only a sampled-diff gate against
  independent ground truth catches that class.
- The genre saturation is the second flavor: a model can also be _nearly
  constant_ — statistically "confident" everywhere while discriminating
  nothing. Any gate that only checked accuracy-vs-truth on a held-out set
  might have missed it; the tell was the distribution, not the score.
- The pivot itself is a finding: **a failed write gate does not mean the
  analysis is worthless — it means the write target was wrong.** Beat
  arrays (the beats ledger in the archive DB) deliver the value without
  clobbering the field rekordbox owns. CrateDeck's
  `archive_grid_cross_check` then uses that ledger as an _independent
  second opinion_ on rekordbox's own grids (real-archive verdict: 46 ok /
  40 off / 2 octave) — which the verify pipeline could never produce,
  because its grid check compared an analysis against itself.

Corollary we now operate by: keep the gate as a hard rule — every future
analysis stage (structure, vocal density, similarity) gets a measured
agreement number recorded in the roadmap doc before anything touches files.

## 2. Model-output skepticism, generalized

The BPM phase-lock joins the family of "the year is always 2023" errors:

1. **flash-lite guesses 2023** for every release year (fixed by SC
   `display_date` verification).
2. **beat_this phase-locks 2.2–2.6% off** (fixed by refusing the tag write,
   keeping the grid as data).
3. **the effnet genre head saturates** (fixed by deferring the write).

The general law: _a model's most dangerous failure mode is not garbage
output — it is confident, uniform, subtly-wrong output that no single
instance raises an eyebrow at._ Defenses that held up this window:

- Ground-truth reads from files, never from our own DB (the audit
  principle).
- Sampled-diff review before any batch (the 24-track BPM sample cost an
  hour and saved 24 wrong tags; the full-library pass would have saved 88).
- Distribution checks, not just accuracy checks (saturation is a smell).
- Provenance stamps (`TXXX:AI-GENRE|0.92`) so AI-filled fields remain
  identifiable forever.
- A human-diff view of what a batch would change before it changes it.

And one more, learned the hard way: **saturated-constant model output is
never believable.** The mood pass shipped with the head label order
inverted — every track read dance=0.00/party=1.00 — and that uniformity,
not any accuracy metric, is what flagged it within minutes.

## 3. Format realities: the writer is where formats bite

FullTags' entire reason to exist is that tag/mux formats punish
generalization. The durable catalog, each empirically proven this window:

- **ffmpeg drops the AIFF ID3 chunk** on remux → AIFF writes go through
  mutagen, in place.
- **ffmpeg's WAV muxer can't carry attached pictures** → WAV art via
  mutagen APIC — and **rekordbox ignores WAV art entirely**, so ingest
  converts WAV→AIFF (lossless stream copy + ID3 frame copy).
- **ffmpeg's ipod (m4a) muxer has no metadata mapping** for bpm/energy/
  mbid/AI stamps and silently clobbers `----` freeform atoms on every
  remux → m4a writes via mutagen too.
- **ffmpeg infers the muxer from the tmp filename** → tmp outputs must
  keep their extension, or "Unable to choose an output format".
- **mp3 is written id3v2.3** for widest hardware compatibility — not
  because v2.4 is bad, but because players are.
- **WAV/AIFF read ID3 TXXX frames** even though they're RIFF containers —
  missing this made every "idempotent" re-run rewrite all 73 archive WAVs,
  forever (see §5).
- **rekordbox reads TKEY on AIFF/MP3 only** (WAV RIFF INFO has no key
  field), and **RB overwrites imported keys on analysis unless Key
  analysis is disabled** — the operational gauntlet that stands between
  tags-in-files and tags-surviving-hardware.

The meta-rule, recorded after bug #6/#8: **every container the writer
touches needs a round-trip test that reads back what it wrote through the
ground-truth reader — and idempotency is per-format.** "Second run changes
nothing" only proves something if it runs on every container in the
matrix.

## 4. rekordbox is a co-author, not a format

The device-library work keeps teaching the same shape of lesson: rekordbox
is an actor in the system with its own opinions.

- Dual-DB reality: OneLibrary (`exportLibrary.db`) for new players +
  legacy `export.pdb` for the XDJ-XZ fleet; a sync is only trustworthy
  when both agree. AlphaTheta's official compatibility matrix maps
  exactly onto this — which is why the N75/N78 player-compat verdict
  (measured dual-DB rows × the matrix) is the single clearest expression
  of what megadj is for.
- The CDJ-3000 v3.30 incident (playlists vanish; firmware prioritized
  OneLibrary; rolled back) is a _class_: venue firmware version is a real
  failure mode, now rendered as informational firmware advisories in
  preflight.
- RB renders covers from `artwork_m.jpg`/`artwork_s.jpg` thumbnails — a
  directory with only `artwork.jpg` silently shows nothing.
- RB treats imported tags as pre-analysis input, to be overwritten on the
  next analysis pass unless explicitly disabled. **Any tag SSOT that
  claims to survive hardware must name its operational gauntlet** — ours
  is "disable Key analysis → Reload Tags → verify", queued for the next
  drive mount.
- ANLZ files go at hash-computed paths; `Content.length` is seconds; PQTZ
  beats are `>4H` hi/lo pairs; PWAV peaks are u8; FAT32 is NFC-ambiguous.
  These are recorded in `docs/usb-sync.md` "hard-won facts" so no one
  relearns them.

## 5. Bugs found _by executing_ — the ones testing never would have caught

Three of the best bugs of the window surfaced only when the shipped code
ran against the real 88-track archive:

1. **WAV/AIFF stamp reads opened the file and read nothing.**
   `readTxxx`'s WAV/AIFF branches returned null for ACOUSTID/CAMELOT/
   ENERGY/AI-\* — so the "idempotent" fingerprint stage re-fingerprinted
   and rewrote all 73 archive WAVs on every run, forever. Every test
   passed, because the fixture matrix ran idempotency checks on mp3 only.
   **Lesson: idempotency claims must be tested per container format.**
2. **Art-embedded files got no energy stamp.** The embedded cover decodes
   as a bogus video stream; ffmpeg's default stream selection fed it into
   the astats graph, the JPEG-as-video decode failed, the whole command
   exited non-zero, and `measureRms` returned null. Fix: `-map 0:a`. The
   four art-embedded WAVs in the archive were the entire miss.
3. **The mood label-order inversion** (§2). Shipped, ran, produced sane-
   looking JSON — wrong for every head except party. The saturated-
   constant tell + a direct ONNX probe + a pinned regression test closed
   it.

The meta-lesson: **the archive itself is the highest-value test fixture
we own.** Synthetic fixtures prove the code does what we said; the real
library proves what we said was the right thing to say. Execution passes
against production data are not a luxury after tests — they are a
different test.

## 6. Engineering invariants that earned their keep

Each of these was paid for at some point; they are recorded here so the
payment isn't repeated:

- **Sync/async boundaries are load-bearing.** `setFileTags`/
  `writePatchSync` must stay sync — bridging via a spawned `bun -e`
  measured 6.4× slower (19 ms → 124 ms per write). Mirror-side:
  CrateDeck's `rbSnapshot`/`checksumLedger` must stay _async_ — spawnSync
  hash loops once froze the server for minutes. The rule in both
  directions: never bridge a sync API to an async implementation through
  a spawned interpreter, and keep the regression benchmark.
- **One writer, one schema.** Every duplicate write path is a future
  corruption. The window deleted the last one (`megadj enrich` now writes
  through FullTags' `writePatch` like everything else); the four-vote
  genre ladder (SC tag → canonical map → MB folksonomy → AI conf-gated)
  converges on it.
- **File-first ground truth.** The DB is a cache; the file is the truth.
  `groundTruth` reading TXXX:ENERGY (it was hardcoded null —
  `readFullTag().energy` always lied, and the audit "verified" nothing)
  is the cautionary tale: a verifier that doesn't read the real source is
  decoration.
- **Every mutating agent tool is annotation-flagged, interlock-guarded
  client-side, and re-checked server-side at enqueue (the TOCTOU guard).**
  Prompts are suggestions; exit codes are law.
- **Realtime streams need heartbeats** (Bun kills silent SSE after ~10s
  — once stranded a finished verify as a phantom "running 0%"), plus a
  phantom-job reaper, plus UI coalescing (SSE `job` events at ~4/s
  otherwise hammer the server during long verifies).
- **Disk-burn guards in the schema:** snapshots capped at 20/drive
  (rolling), events at 2000/drive, enforced in migrations — agent notes
  ride the event cap automatically.
- **Unknown never fakes ready:** `overall()` refuses to report healthy
  when every check is unknown; preflight's worst-status-wins verdict and
  exit-1 gate make that machine-checkable.

## 7. Product learnings

- **The product's sharpest feature fell out of data we already collect.**
  The player-compat verdict (`works on: XZ ✓ / AZ ✗`) is a join of
  Pioneer's public matrix with measured dual-DB row counts — an hour of
  glue that rekordbox itself cannot answer. Look for more joins of
  "public knowledge × measured local truth".
- **The gate that failed made the product better.** Blocking TBPM writes
  forced the beats ledger, which enabled the independent grid
  cross-check, which is now one of the most interesting reads in
  CrateDeck. The roadmap's gate discipline didn't just prevent damage;
  it rerouted effort to a better target.
- **Ledgers beat tags for contested fields.** Tags are for what hardware
  reads (and only where formats allow); the DB ledger is for everything
  else — beats, mood mirrors, cues, fingerprints. The split is now
  explicit: TKEY/genre/year/energy live in files; beats/downbeats/
  phrase-cues live DB-side; mood lives in both (stamped + mirrored).
- **Agents are operators, not gimmicks** — but only because the surface
  makes safe operation _the default_: readonly handles physically can't
  corrupt state (`readonly: true` sqlite), mutating tools are flagged and
  interlocked, attribution (`jobs.origin`) makes every action
  answerable, and `deckctl prep` gives a headless loop a digest instead
  of a dashboard. The 26-tool MCP surface is now the same product, 1:1,
  for humans and agents.
- **Weekly cadence beats dashboard glancing.** B17 automation (mount →
  light scan; weekly verify) plus O83 `deckctl prep` mean the tool comes
  to you. The dashboard's job is to be boring.

## 8. Process learnings

- **Docs drift behind code in hours, not weeks.** Both audit passes
  (pass 3: 10 findings; pass 4: 7) were dominated by _shipped-status
  staleness_ — tools counted wrong (10 → 19 → 17 → 21 across four docs),
  features listed as open the same day they shipped. The fix that held:
  counted-and-census-verified claims
  (grep the code for the number, don't remember it), and re-running the
  link checker after every edit.
- **Claims need provenance in docs too.** "98 tests across 11 files"
  (verified — the original draft said 12, caught by re-running the
  census), not "94 tests" (remembered). The audit file now records the
  census commands alongside the claims.
- **Concurrent agents on one repo:** the window had multiple agents
  landing work in the same tree. What worked: re-read before editing,
  stage explicit paths (never `git add -A` when another agent is
  mid-flight — one commit accidentally swept a concurrent agent's QA
  changes; the changes were good and gated, but the discipline is: stage
  your files), and let in-flight edits settle before running the full
  gate.
- **Fix-all rounds with regression tests** (GetDat r1–r3, FullTags
  5-bug, CrateDeck r1–r3) outperform ad-hoc fixes: 30+ bugs closed in the
  window, each with a test that pins it. The pattern: audit the
  subsystem, fix everything found, regression-test each, record the
  _class_ in AGENTS.md so the next agent inherits the scar tissue.
- **The cap rule held.** Ideas entered the backlog only when something
  shipped or left. Two items were struck outright (Engine DJ, Serato —
  principles violations), one deleted (affinity model), several shipped
  and closed. The parking lot stays navigable because leaving is real.
