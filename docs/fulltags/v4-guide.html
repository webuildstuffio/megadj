How to read a comment

Each comment is a left-to-right string of tokens. Every token is optional — if it's present, it means something. If it's absent, that data wasn't available.

E1 – E9

Energy band. E1 = chill, E9 = peak energy. Ranked across the entire library so E5 is always your median.

IN:32 OUT:16

Mix window in bars. IN:32 = 32 bars of instrumental at the start you can blend over. OUT:16 = 16 bars clean at the end.

Drop / Roll

Drop = build-and-release structure (big chorus). Roll = steady groove, no dramatic drops.

Hard / Soft

Aggression relative to the track's own genre. Hard techno is Hard. A gentle techno track is Soft — for techno.

Dark / Euph

Happiness relative to genre. Dark = bottom 20% of its genre family. Euph (euphoric) = top 20%.

VAR

Variable tempo. The BPM shifts enough that beatmatching may need riding. Rare (~4% of tracks).

· Subgenre

After the dot: the secondary subgenre (what primary genre alone doesn't tell you). + adds a third genre when available.

Absent token

A missing token means "not applicable" or "not enough data". No IN/OUT = no phrase analysis available. No mood word = middle of the pack.

IN/OUT bar counts

Bar counts tell you how much clean instrumental music is at the start and end of the track — your mix window. Always rounded down to a safe minimum.
